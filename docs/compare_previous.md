# 이전 프로젝트와 비교 (2026-11-19)

이전: `PJT2_결과물 회계튜터`(읽기만 함). 현재: `회계튜터`(처음부터 새로 만듦, 이전 코드는 복사하지 않음). 아래 수치는 이번에 두 폴더에서 직접 명령을 돌려 얻은 값이다.

| 항목 | 이전 | 현재 | 확인 방법 |
|---|---|---|---|

| 검색 평가(이전 25문항 `search_eval.jsonl`) | hit@3 25/25 = 100% (최신 10회분) | 같은 평가셋을 돌리지 않음 | 이전 폴더에서 `scripts/eval_search.py` |

**점수를 직접 비교하면 안 된다.** 질문셋·문항 수·범위(최신 10회분 vs 전체 회차)가 다르고, 이전 점수는 평가 질문을 본 뒤 동의어를 붙여 만든 값이라 후하다. 현재 15문항 평가는 정답 목록을 넓혀 전체 회차 기준으로 쟀고, 동결 30문항은 질문을 쓴 뒤 한 번만 잰 값이다.

## 검색 방식
- 이전: 질문에서 낱말을 뽑아 FTS5·LIKE 로 후보를 찾고 일상어는 사전으로 공식 용어로 넓힘. 기본 최신 10회분.
- 현재: 같은 계열(FTS5·LIKE + 희귀도 점수 + 동의어)이며 기본이 전체 회차, 점수가 같으면 최근 회차 우선. 요약 카드는 이 결과의 상위 문항에서 핵심어가 충분히 맞은 것만 사용. 벡터 검색은 둘 다 쓰지 않는다(현재는 보류, `docs/vector_search_review.md`).
