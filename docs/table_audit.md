# 표 보존 점검 (문항 속 표)

원본(확정답안 PDF·HWP)의 표를 `scripts/extract_tables.py` 로 뽑아 `data/tables.json` 에 머리글·칸·병합(rowspan·colspan)과 함께 저장하고, 문제 화면·O/X·노트 대표 기출에서 HTML 표(`<table>`, 머리글 `<th scope>`)로 보인다.

## 방법

- PDF: PyMuPDF `find_tables()`. 숫자 끝에 따로 찍힌 쉼표·점은 칸 안 글자 좌표로 다시 모아 '3,000,000,000원' 으로 읽는다.
- HWP: 기존 `hwp5html` 변환 결과의 `<table>`(rowspan·colspan 그대로). 안쪽 표가 든 바깥 표는 안쪽 표만 쓴다.
- 문항 연결: 문항 번호(1→15 순서)와 '[답]' 줄 사이의 표만 그 문항의 표로 본다. 표 칸 글의 80% 이상이 DB 문항(문제+보기)에 있어야 받는다.
- 머리글: 맨 윗줄에 숫자·'ㆍ' 글머리가 없는 이름표만 있으면 머리글(걸친 칸이 있으면 걸친 줄 수만큼), 아니면 머리글 없음. 연도·기수('2025년', '제1기')는 이름표로 본다.

## 알려진 한계

- 보기 ①~④가 표인 문항(예: 113-7)은 표에도 보기가 들어 있어 보기가 두 번 보인다(열 이름과 값의 연결을 지키려는 것).
- 한 문항에 표가 둘이면 원본 순서대로 모두 보인다. 문제 글(텍스트)은 원본 그대로이며 표 글자와 겹친다.
