## 5. 구조적 관찰
- 규칙이 '처음 맞는 것' 방식이라, 질문 문장에 단원 낱말이 없는 53문항(약 10%)은 **보기·해설에 우연히 들어 있는 낱말**로 정해진다(예: 업무용승용차, 재고자산 평가, 결손금).
- 같은 주제가 여러 단원으로 갈라진 묶음: 외화환산(4문항 → 3단원), 업무용승용차(법인세 4문항 → 2단원 + 소득세 1), 부당행위계산(4문항 → 2단원), 결손금·이월결손금(3문항 → 2단원), 법인세법상 재고자산 평가(3문항).
- 문항이 1~3개뿐인 단원: 재무 리스 1·결산·발생주의 2·법인세회계 3, 세무 소득세 금융소득 1·퇴직·연금·기타소득 3, 원가 관련원가·의사결정 3. 공부 순서 표에서는 5문항 미만이라 항상 '기록 부족'이 된다.
- 이전에 '사람 검토 필요'로 남긴 '자본' 오분류 5문항, 개별원가·원가개념 태그와 같은 계열의 문제다.

## 핵심 발견 요약
1. 540문항이 재무·원가·세무 3과목 42개 (과목·세목·단원) 칸으로 나뉘고, '기타'는 14문항(2.6%)뿐이며 전부 기존 단원으로 옮길 수 있다(4절).
2. 질문 문장에 단원 낱말이 없는 53문항이 보기·해설 낱말로 태그되어, 같은 주제가 여러 단원으로 갈라진다(외화환산 4문항→3단원, 업무용승용차, 부당행위계산, 결손금).
3. 명백한 오분류 의심은 124-3(현금흐름표), 126-5(회계변경), 74-3(수익인식), 114-7(공손·결합원가), 75-14·77-13(부가세), 68-13·75-15(원천징수) 등이며, 문항 수가 1~3개인 단원은 공부 순서 표에서 항상 '기록 부족'이 된다.
